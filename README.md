# Venus · versiones

## 📱 iPhone

Abre en **Safari**: **https://gastonstrato.github.io/venus-releases/app/**

Después toca **Compartir** (el cuadrado con la flecha) › **Agregar a pantalla de inicio** › **Agregar**. Venus queda como una app más, funciona sin internet y se actualiza sola.

## 🤖 Android

Descarga la última versión: [Venus-1.5.0.apk](https://raw.githubusercontent.com/gastonstrato/venus-releases/main/Venus-1.5.0.apk)

Si ya tienes Venus instalada, no hace falta descargar nada: la app avisa sola cuando hay una versión nueva.
